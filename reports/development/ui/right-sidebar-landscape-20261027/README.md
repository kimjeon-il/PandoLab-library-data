# 휴대폰 가로 화면 우측 사이드바 구현

> 원본·출처: Pando 앱 템플릿, 공통 CSS, 관련 브라우저 검사 및 첨부 변경 패치

## 변경

편집기 phone-landscape에서 메뉴 버튼과 작업 내비게이션을 하나의 우측 컨테이너로 묶었다. 상단 메뉴는 고정되고 아래 도구 목록만 스크롤한다. 기존 버튼·이벤트·화면 소유자를 사용하며 별도 상태는 추가하지 않았다. 패널·메뉴는 막대 왼쪽에 열리고 지도 가림 여백도 막대와 패널의 합을 반영한다. 웹에 편집 사이드바를 추가하지 않았다. 세로 모드의 하단 막대와 기존 햄버거 위치는 유지한다.

일반·선택·호버·선택+호버의 메뉴 버튼 색상을 기존 내비게이션 규칙과 통일했다. 상단/우측 안전 영역은 막대뿐 아니라 패널과 메뉴에도 반영한다. 기존 지도 소비자가 getComputedStyle 값을 숫자로 읽기 때문에 네 개의 좌우 여백 속성은 CSS length로 등록하여 calc/min/env 결과가 실제 px로 전달되게 했다.

## 실행한 집중 검증

- 최종 관련 브라우저 6건 통과: `phone-landscape-surface-contract`, `phone-landscape-editor`, `button-consistency` 중 phone landscape, touch landscape navigation, landscape menu shares, narrow portrait navigation 사례만 실행.
- 640×360·844×390 배치, 200% 글자 크기, 내비게이션 스크롤 중 메뉴 버튼 고정, 일반/선택/호버/선택+호버 계산 스타일 일치 확인.
- 640px 배치 표본은 제공되는 CSS env를 상단24px·우측12px로 대체해 안전 영역을 모의했다. 패널·메뉴·햄버거 모두 상단24px 아래에 위치하며 패널이 막대와 겹치지 않음을 확인했다. 실제 Android 시스템바 측정이 아니다.
- 실제 앱 프런트엔드에서 메뉴→파일→뒤로→Esc 포커스 복귀, 패널 전환, 키보드 높이 변화, 화면 회전, 초안·실행 취소·다시 실행 및 지도 위치 보존을 검사했다.
- 별도의 웹640·844 검색/선택 및 앱 세로 화면 햄버거·뷰포트 회귀 3건 통과.
- 최종 `check-ui-spacing` 통과(1838규칙), `check-ui-components` 통과(28 primitives, 140버튼).
- 마지막 코드 리뷰 지적 2건(열린 패널/메뉴의 상단 inset, 선택+호버 우선순위)을 수정했고 재검토에서 추가 문제는 없었다.

회귀 검사 작성 후 기존 좌측 배치에서 실패함을 확인한 뒤 구현했다. 중간 배치 표본에는 기본 box-sizing 링크 누락과 파일 메뉴의 mobile-open 상태 누락이 있어 실제 구조에 맞게 수정했다. 최종 검사는 서버를 새로 시작해 실행했다. 전체 테스트·C++ 빌드·GIS 검증·앱 패키징은 실행하지 않았다.

## 실제 화면과 한계

`editor-landscape.png`는 실제 앱 프런트엔드의 Chromium 브라우저 화면이다. 독립적인 새 화면 목업이 아니다. Windows 개발용 WebView는 기존 검증된 native 입력 `2596d458378169db5e51d5756fc3d7d6ce0c7fe4e722186f598c6b4cdbeafd50`으로 실행했고 세로 화면을 관찰했다. 창 크기·포커스 제어 도구가 가로 전환을 완료하지 못해 실제 WebView 가로 동작은 미검증이다. Android 실기기 시스템바·터치도 미검증이며 모의 안전 영역 결과와 구분한다.

## 반영 범위와 첨부

로컬 work/ui 수정과 집중 검증까지다. main 병합·앱 코드 푸시·웹 배포·앱 실행 파일 갱신은 하지 않았다. 동시에 진행된 다른 채팅 변경은 수정하거나 포함하지 않았다. 아래 패치는 이번 변경 7파일만 포함한다.

- `changes.patch`: 위 기준 커밋에 적용되는 변경
- `editor-landscape.png`: 우측 막대와 왼쪽 상세 패널 화면

Web/App 공통 프런트엔드는 기존 생성기로 재생성한다. 유지되는 생성 캐시는 현재 work/ui 개발 프런트엔드 포인터가 소비하며, 새 배포나 설치 패키지를 뜻하지 않는다.
