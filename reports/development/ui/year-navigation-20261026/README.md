## 변경과 경계

- 세계지도 자료 보기의 일반 화살표는 1년, 겹화살표는 10년 이동한다. 연도별 조회는 연말, 올해는 현재 월을 사용한다. Core의 기존 월 조회와 BCE 산술을 재사용하며 연도 0은 생성하지 않는다.
- 첫 표시는 연도와 실제 조회 기준을 함께 제공한다. 파일에서 복원한 과거의 중간 월을 임의로 연말로 옮기지 않는다. 이 경우 `6월말 기준`처럼 실제 월을 명시한다.
- 날짜 입력창의 월별 보기에서 기존 native 월 드롭다운과 한 달 이동을 제공한다. 사용자 후속 지시에 따라 `data-native-select` 제외 설정을 복원해 검색 입력형 combobox로 변환되지 않게 했다. 보기 단위도 같은 native 선택 방식을 사용한다.
- 연/월 단위의 미제출 선택은 초안이다. 성공한 조회만 표시 단위를 변경하며 실패·취소·오래된 응답은 표시 시점이나 포커스를 잘못 바꾸지 않는다.
- 월 이동 버튼을 키보드 Enter로 조작할 때 폼 전체 제출이 가로채지 않게 수정했다. 기존 편집기 월 표시 helper의 의미와 모든 원본 날짜는 보존한다.
- 날짜 중심 버튼은 공통 아이콘 도구 높이와 맞춘다. 아이콘 버튼은 공통 36px/모바일 40px, 이동 버튼은 기존 dialog action 규칙을 사용한다. 모서리·글꼴·아이콘 중앙 정렬은 공통 토큰을 사용하고 날짜 창의 별도 버튼 높이 예외를 제거했다.
- 프로젝트 날짜 탐색, 자료 변환, GIS·C++ 변경, main 병합, 원격 코드 push, 웹 배포, 앱 패키징은 수행하지 않는다.

## 검사 방법과 현재 결과

- 기존 구현이 연 이동 시 임의의 6월을 유지하는 동작을 재현해 연말 조회 회귀 검사를 먼저 실패시킨 뒤 구현했다. native 드롭다운 계약과 Enter 이벤트 회귀도 실패 후 통과를 확인했다.
- timeline controls, builtin clock, Web/App HTML 계약 단위 검사 19건 및 대상 ESLint 통과.
- 실제 Edge의 WebGL 세계지도에서 PC·1024·800·390·320px 날짜 입력, 연/10년 이동, BCE·확장 연도, 월 드롭다운, 월 버튼의 Enter 동작, 취소, 프로젝트 원본 보존을 확인했다. 첫 full flow 및 UI 수정 후 full flow가 통과했다.
- 편집기 Canvas 브라우저에서 PC와 휴대폰 가로 크기의 기존 시점 문구·지도 조작·문서 상태를 별도로 확인했다. 프로젝트에 날짜 탐색 버튼이 추가되지 않았다.
- 공통 버튼 fixture는 현재 product template/fragment/public source resolver로 갱신했다. PC 1440px와 320px 규격 검사 모두 통과했다. fixture에서 스타일 비교를 위해 임시로 연 popup을 닫은 뒤 기존 닫힌 toolbar 폭 검사를 수행한다. 실제 popup 폭은 위 세계지도 full flow에서 별도로 검증한다. 이동 버튼의 높이·모서리·글꼴은 일반 dialog action과 같고 월 이동 아이콘의 중심 오차는 각 축 1px 이하다.
- 최종 고유 시나리오는 버튼 PC, 버튼 320px, viewer 날짜·반응형 흐름, editor Canvas 시점 문구·문서 보존의 4개다. 수정 뒤 관련 실패와 새 계약만 재실행했다. 전체 브라우저 검사를 실행하지 않았다.
- 일부 재실행과 증거 복사 시도는 다른 작업의 library storage lock 때문에 실행 전에 종료됐다. 다른 작업의 lock은 수정하거나 제거하지 않았고, 해제 뒤 같은 canonical 검사를 재실행했다.
- 최종 커밋의 공통 Web/App frontend 생성 검사가 통과했다. 1,104개 자산, frontend input SHA-256 `4085d68bdc1145e335cd31e3a120b4fbb9c33c3d1ebf3110d99142c3eaaa89fa`. 고정 runtime pin `68380579a7c7a1bd8ec97683b7517502c1389c3c`는 변경하지 않았다. 원본 GIS·저장 형식·C++ 입력은 바뀌지 않았다.

## 한계와 증거

전체 테스트·C++ 빌드·GIS 검사·실제 WebView 실행·사용자 사용성 검증은 실행하지 않았다. App 확인은 편집기 frontend의 실제 브라우저 검사이며 실제 WebView 검증과 구분한다. 원본 자료의 역사적 날짜 정확도를 새로 검증한 작업은 아니다.

[PC 실제 화면](desktop.png), [320px 실제 화면](mobile-320.png). 두 대표 화면 1,297,308바이트를 현재 검증 근거로 보관하고, 테스트 출력 복사본 7개와 일회용 helper 1개 등 2,776,143논리 바이트 및 빈 디렉터리 3개를 제거했다. D 여유 공간의 순간 실측 증가는 1,863,680바이트이며 동시 작업의 쓰기 영향도 포함될 수 있다. 대상과 크기는 [cleanup.json](cleanup.json)에 별도 기록했다. 남은 작업 임시 파일은 없다. 이 범위만 보고서 전용으로 원격 보관하고 검증한다. 계획은 앱 저장소의 `docs/superpowers/plans/2026-10-26-year-first-timeline.md`에 둔다.
