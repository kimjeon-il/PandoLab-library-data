## 결과

- 공개 웹의 자료 기준은 Pando main의 config/library-data.json 한 곳이다. 완료한 런타임 자료를 보관·푸시·원격 확인하고 검증한 핀을 main에 반영하면 기존 Pages 배포와 실제 응답 검증까지 이어진다.
- 별도 자료 채널 덮어쓰기, 독립 게시 workflow·조립·복원 도구, 앱의 공개 Web 게시 버튼과 JS/Rust 명령·등록·권한을 제거했다. 저장·동기화·충돌 해결과 앱의 고정 자료/오프라인 실행 경로는 유지한다.
- Web/Worker는 같은 빌드 메타데이터와 자료 해시를 사용한다. 고정 세계지도 manifest를 필수로 전달하고 오래된 Worker/자료 버전 조합을 거부한다. 배포 중 전체 GIS 생성이나 자료 저장소 쓰기를 실행하지 않는다.
- main: 6a13356609dedd25c258f7f00a8aedbff4f18450; 자료: 68380579a7c7a1bd8ec97683b7517502c1389c3c. 첫 구현 커밋 97478813a, Linux 거부 푸시 테스트 보강 5f0732dab. 다른 GIS 검증 커밋 22개는 work/gis에 보존하고 main에 포함하지 않았다.
