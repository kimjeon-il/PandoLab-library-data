# Map Toolkit 비공개 Work 실행·파일 반환 검증

> 보고서 ID: `PL-MAP-PRIVATE-WORK-001` · 상태: `workflow-verified-with-limitations` · 지도 반영: `not-applied` · 색인일: 2026-10-25  
> 원문 최종 수정: 2026-10-25  
> 조사 기준: 실행 소스 `ec658aa7132c0f57e5beddf6f5f83c8b3ae99db7` / 앱 빌드 해당 없음

## 대상과 기준일

Map Toolkit의 개인용 비공개 Work 설치본 0.4.1을 검증한다. 0.4.0은 실제
비공개 모델 전달 검사에 사용됐으므로 제품 설치본은 다음 패치 버전이다.
소스는 기존 work/ui의 두 작업 커밋 a01a8097c와 ec658aa71로 커밋·푸시했고,
설치본은 후자의 전체 SHA와 자료 핀 127e51c3457df87786ecf3aa5ad98ded690928df를
고정했다. 이 작업에서 앱 main 통합·앱 빌드·학습·공개 플러그인 제출은 하지 않았다.

완료 판단은 검토를 거치는 작업 흐름이며 독립 모델 정확도·역사 정확도가 아니다.
동일 대화의 활성 환경에서 다음 턴 이어 작업만 검사하며 환경 만료 후 복구는 보장하지 않는다.

## 근거와 방법

Plugin Creator의 공식 비공개 등록·업데이트를 사용했다. 모델 전달을 먼저 확인한
뒤 제품 실행 코드를 변경했다. 새 Work에서 첨부·ZIP·PC·관리용 아카이브 조회 없이
실제 설치된 모델 16,697,571바이트와 명세·보조 파일을 읽고 해시·실행 결과를 확인했다.
그 증거는 private-reference-gate.json에 있다. 가중치는 공개 코드·이 보고서에 없다.

제품 배포는 공통 소스 수집·정확한 npm 의존성·파일 검증·압축 도구를 cloud-probe와
공유한다. 기존 C++/WASM·Tesseract·ORT·Pillow/PyMuPDF와 자료를 재사용하며 별도
서버나 환경을 만들지 않았다. 원본 코드·WASM 서명을 실제 패키지에서 검증했다.
패키지는 210파일/28,152,224바이트, ZIP은 23,478,734바이트였다. 제품에는 시험 지도,
기준점, 진단 텐서와 학습 환경이 없다. 설치 서비스가 만든 메타데이터를 포함한
설치 파일은 211개이고 모델은 하나다. 퇴역 preflight 스킬과 중복 모델은 제거했다.

원본 수집은 기존 학습 CLI와 플러그인이 같은 bounded downloader를 사용한다.
JPEG/PDF/PNG/WebP·권리 확인·해시·취소·원본 보존을 유지하며 HTTPS에서 HTTP로
내려가는 리디렉션도 요청 전에 차단한다. 최종 검토의 해당 결함은 실패하는 검사로
재현한 후 수정했다. 단순 디렉터리명·수정일을 근거로 원본을 삭제하지 않았다.

## 실제 관측 결과

### 설치·실행환경

- 개인용 비공개 설치, Map Toolkit 이름과 지도 아이콘, 버전 0.4.1을 확인했다.
- 새 Work의 Linux 환경에서 Node 24.22.1/Python 3.12.14로 실행했다.
- 빈 캐시에서 정확한 Node 의존성을 준비했고 이후 cacheHit:true를 확인했다.
- 모델은 설치된 관리 파일을 직접 읽고 런타임 캐시에 다시 복사하지 않는다.
- 누락·변조 자료 거부, 경로 탈출·링크·기존 임시파일 보존은 관련 단위 검사로 확인했다.
- 예전 0.4.0 전달 검사 대화는 갱신 후 현재 실행 패키지를 찾지 못했다. 이 시도에서는
  지도 분석을 하지 않았다. 현재 설치본을 다시 선택한 새 Work에서 별도 검증했다.
  구 작업의 서명을 새 것으로 바꾸거나 호환 경로를 추가하지 않았다.

### 흑백 캐나다 지도와 실제 파일 반환

자료는 NRCan의 전국 흑백 지도 1페이지다. 도면 저작권 2024년과 PDF 생성일
2024-02-28을 확인했으며 지도 내용의 별도 기준일은 확인하지 않았다. 원본은
841,931바이트, SHA256 358cfad7e8329f019c820bc0b9e83b482e721eb09ebf6106d2e1580623f0b1b4다.

공식 지도·OGL-Canada 조건 검색은 수행했으나 공식 FTP 원본들은 HTTP503이었다.
첫 보관본 힌트는 원격에 없는 보고서 소유자 리비전으로 잘못 지정해 HTTP404였다.
원격 main을 다시 확인하고 a5165a0a0c2a9ce921d30d1a536039b63be5d046의
동일 원본 보관본을 사용했다. 익명 HTTP200과 원본 해시를 확인했다. 제어하는 Codex가
이 보관본을 조사·전달했고 최종 사용자에게 지도나 ZIP 첨부를 요구하지 않았다.
공식 원본 URL·보관본 URL·기관·이용 조건은 GeoJSON 출처까지 보존됐다.

- 제품 기본 maxPixels=4,000,000을 유지했다. PDF의 144dpi 원본/분석 영상은
  1584×1224이므로 원본을 불필요하게 확대하지 않았다.
- 실제 OCR과 ONNX 12타일 추론은 47.221초에 완료됐다. OSD가 영문을 Cyrillic으로
  오판해 rus/ukr를 실제 지연 다운로드하고 실행했다. 후보는 선551/면2였다.
- 원본의 영문을 확인해 eng를 명시한 새 작업은 21.799초, 지명 검출180개였다.
  자동 대응은 신뢰할 수 없어 위치를 확정하지 않았다.
- 다음 턴에 기존 검토 기록의 기준점 입력만 적용했다. 기존 작업 JSON·서명은
  재사용하지 않았다. 정합만 수정한 전후 segmentation.signature와 픽셀 경계망 해시가
  같고 OCR/모델 단계가 실행되지 않았음을 실제 기록으로 확인했다.
- 원본과 대조한 Alberta–Saskatchewan 경계 선분 line:294 하나만 선택했다.
  나머지 선과 모든 면은 제외했다. 지명·범례·경위선 오검출이 많다.
- 네 결과물과 완료 명세를 실제 다운로드해 모든 바이트 해시를 대조했다.
  파일은 downloads/에 한 번만 보관했다. 보고서에는 Codex 감사 내용을 덧붙였고
  최종 complete.json 해시 갱신 사실과 최초 엔진 명세 보존을 명시했다.

**이 정합은 정확도 목표를 통과하지 않았다.** 제공한 일부 UV가 도시 기호 중심과
어긋나고 전국 곡면 지도에 affine을 적용해 RMS 380,794.331m/최대 549,988.974m
잔차가 남았다. GeoJSON은 작업 흐름 확인용 잠정 선분이며 정확한 전국 경계 데이터가
아니다. 수동 검토 표시를 위치 정확도 승인으로 해석하면 안 된다. 모델은 계속
pending/trainingOnly:true/releaseApproved:false이고 미관측 채널을 추출했다고 표시하지 않는다.

### Pando와 휴대폰

실제로 다운로드한 GeoJSON을 Pando의 일반 객체 가져오기로 열고 형상 편집,
일괄 Undo/Redo, GeoPackage 저장·재열기를 기존 브라우저 검사에서 확인했다
(1/1 통과, 본 검사18.8초). 전용 분석 화면이나 앱 재빌드는 사용하지 않았다.

2026-10-25 사용자는 실제 휴대폰에서 PC Remote를 연결하지 않고 플러그인 선택,
동일 작업 재내보내기와 GeoJSON 다운로드가 모두 됐다고 확인했다. 이는 사용자
실측 보고이며 폰 로그나 스크린샷을 별도로 수집한 자동 검사는 아니다.

보장하는 검사는 아니다.

### 코드 검사와 검증 한계

관련 Node 준비/패키지/CLI/probe15개, 기존 엔진·가져오기19개, 수집 Python9개,
자료 복원1개, Pando 브라우저1개와 변경 파일의 ESLint가 통과했다. 스킬 검증도
통과했다. 스킬의 독립 시나리오 검사는 변경 전 PC·첨부를 요구하던 동작이 변경 후
클라우드 검색으로 진행하고 실측 전 완료 주장을 하지 않는 것으로 바뀐 것을 확인했다.
전체 검사·전체 앱 빌드·재학습은 실행하지 않았다.

새로운 지역의 자동 탐색 성공률, 경계 정밀도·재현율, 독립 확인점 정확도는 합격으로
판정하지 않는다. 실제 예제에서도 자동 정합을 확정할 근거가 부족했고 오검출이 많았다.
출처 검색·불확실성 검토·수정의 소유자는 Codex이며, 현재 모델은 후보를 제공한다.
OCR/추론 각각의 별도 단계 시간과 최대 메모리를 계측한 것은 아니며 위 시간은 전체
분석 실행시간이다. 환경 만료 뒤 복구나 구 버전 대화의 자동 갱신도 합격 범위가 아니다.

  할 때마다 패키지·모델·전체 자료 저장소를 복사하지 않는다.

## 데이터 반영과 공개 범위

실제 국가·유효기간·이름·역사적 귀속은 반영하지 않았다. 이 범위는 공개 시험 지도와
그 실행 근거만 포함하고 비공개 등록 ID·지원 파일 참조 ID·인증/서명 링크·모델
가중치를 포함하지 않는다. 사용자 지도와 일반 작업 결과를 자동 게시하지 않는다.
코드 배포의 소스 SHA와 보고서 보관 revision은 독립적이며 런타임 자료 핀을 유지한다.
