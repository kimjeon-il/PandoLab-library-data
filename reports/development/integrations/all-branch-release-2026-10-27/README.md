## 충돌과 추가 회귀 수정

자료 핀은 한쪽을 그대로 선택하면 다른 변경을 잃는다. 최신 GIS를 보존한 뒤 세 범위의 결합 자료 핀으로 교체한다. 제품 자산 테스트는 정본 frontend snapshot을 사용하는 두 브랜치의 검증 조건을 모두 유지했다.

병합 전 독립 코드 검토에서 수계 계약과 국가 편집 사이의 오류를 찾았다. 실제 WASM 합성 프로젝트에서 다음 실패를 재현하고 수정했다.

1. 강을 포함한 프로젝트의 국가 편집이 `TIMELINE_GEOMETRY`로 실패했다. 마지막 검증이 모든 소유자를 Polygon으로만 보던 원인이었다. 수계의 선형 형상을 허용하되 국가에는 Polygon 제한을 유지한다.
2. 같은 문자열 ID의 국가를 바꾸면 수계 형상도 바뀌었다. 정적 국가 교체의 필터·검색을 전체 ObjectRef로 바꿨다. 다른 ID의 물 이력도 국가 교체에서 보존한다.
3. 여러 시기 형상을 가진 물의 메모 수정이 `water geometry binding required`로 실패했다. 메타데이터 수정은 형상 연결을 새로 쓰지 않으며, delta에서도 물 형상을 정적 inline geometry로 취급하지 않도록 했다. 잠금·메모·Undo/Redo와 형상 이력을 함께 확인한다.

수정 커밋은 `8bc9c5030`이다. 실제 국가 형상 변경 결과와 수계 보존을 확인하는 작은 회귀 3개를 기존 테스트에 추가했다. 정본 저장 항목의 null geometry와 현재 투영 형상을 혼동한 이전 메타데이터 테스트도 현재 소유자의 투영을 사용하도록 고쳤다(`5f7ff7c4f`). 실제 준비 의존성에 등록된 형상 참조를 유지하고, 렌더러 준비 revision은 문서 revision과 구별해 검사한다. 검사 삭제·skip으로 실패를 숨기지 않는다.

WASM만 기존 SDK와 main의 고정 `build-native/wasm`에서 빌드했다. 새 SDK·Rust target·설치 패키지는 만들지 않았다. 최종 소스 및 바이너리 짝 검사도 통과했다. 소스 SHA `feca29c8b2b72781222f8ff76c0572af5884fae5e5cf715102bb8af7d097279b`, WASM SHA `3d71fbd75cfd19bb60e18ce36082443c5e6b3fc55de38ff00ce660032858e55f`.
