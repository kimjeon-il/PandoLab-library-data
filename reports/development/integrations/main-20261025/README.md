## Pages 준비와 한계

통합 커밋의 게시 파일 1,732개, 213,081,702 bytes를 고정된 main 검증 위치에 준비했다. committed source 바이트·출력 SHA256·생성 메타데이터 검사를 통과했고 자료 핀은 `e6b41735`와 일치한다. shared 소스 168개·앱 소스 138개가 게시물에서 제외됐다. 이는 로컬 Pages 준비 검증이며 원격 Actions나 라이브 배포 성공을 뜻하지 않는다. 첨부 Pages manifest는 해당 커밋·핀·전체 게시 파일 해시의 기록이다.
