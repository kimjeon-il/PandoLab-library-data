## 적용한 계약

날짜·화면·프로젝트 세대의 변경은 입력 평가를 요청하며 그 자체로 표시 자원을 폐기하지 않는다. 기존 소유자가 출처·내용, 생성 조건, 실제 그래픽 장치/컨텍스트 세대, 표시 조건을 제공하고 상태 없는 `resource-update-policy.js`가 입력·CPU·GPU·표시 갱신을 구분한다. Classic Canvas Worker용 어댑터는 같은 모듈에서 생성한다.

동일 원본 강·호수 Worker 강제 재시작, 같은 GPU의 프로젝트 변경 초기화, `preserveBuiltinMesh` 예외 전달, 프로젝트 세대가 포함된 선형 GPU 자원 키, 검색의 무관한 전체 revision 기반 DOM 재생성 등을 대체·삭제했다. 국가·경계·지명·라벨의 실제 입력을 비교하며 Core 입수 시 같은 불변 형상 할당을 재사용한다. 선택·편집·이력과 오래된 응답의 공개 제한은 프로젝트별로 유지한다. 이미 올바른 국기·이미지·폰트의 브라우저 자산 캐시는 수정하거나 복제하지 않았다.

## 실제 확인

Windows Edge, 1440×900 CSS px, DPR 1의 고정 그리스 주변 지구본에서 UI로 2026-09 → 2026-10 → 2026-09를 선택했다. 조회와 새 문서 수용은 실행되지만 아래 단계는 반복되지 않았다.

| 실행 경로 | 국가 전체 메시 | 공유 경계 준비 | 강·호수 GPU 업로드 누적 bytes | 지형 업로드 누적 횟수 | 추가 자료 요청 / Worker |
|---|---:|---:|---:|---:|---:|
| WebGL2 이전 → 이후 | 1 → 1 | 2 → 2 | 15,759,004 → 15,759,004 | 28 → 28 | 0 / 0 |
| Canvas Worker 이전 → 이후 | 해당 없음 | 3 → 3 | GPU 미사용 | GPU 미사용 | 0 / 0 |

WebGL에서 256 KiB 이상 `bufferData` 할당 횟수도 날짜 왕복 동안 증가하지 않았다. 실제 컨텍스트 손실·복구 후 자원을 다시 준비하고, 이어진 동일 자료 날짜 이동에서는 큰 버퍼를 중복 할당하지 않는 검사까지 통과했다. 초기 표시 순서 검사에서는 배경 20,430.9 ms → 국가 20,484.7 ms를 기록했다. 지형 요청을 의도적으로 보류한 회귀 검사 수치이며 일반 불러오기 속도 보장이 아니다. 최초 국가 메시 준비 11,534.9 ms, 재진입에서는 전체 준비 단계 자체를 생략했다. 이전 준비 시간 진단값은 새 계산이 아니므로 갱신하지 않는다.

실제 WebView2 개발 앱에서는 `webgl2`, 프로젝트 세대 0, 공유 경계 준비 3회 상태에서 컨텍스트를 손실·복구했다. 추가 경계 계산 없이 같은 프로젝트가 준비 완료로 돌아왔다. 첨부 `native-recovery.png`를 시각적으로 확인했다. 앱의 현재 편집 화면에는 날짜 이동 UI가 없으므로 **앱 날짜 왕복은 검증하지 않았다**. 검증을 위해 프로젝트에 날짜 이동을 추가하지 않았다. 실제 사용자 사용성 검증도 수행하지 않았다.

## 회귀 수정과 검사 범위

- 캐시 A → B 계산 → A 재사용 시 이전 B의 완료가 A를 덮던 토큰 무효화 누락을 수정했다.
- 복구 완료한 메시의 컨텍스트 의존 키를 갱신하고 교체 할당을 해제한다.
- 경계 업로드 완료 후 다시 그리기를 빠뜨리던 경로와 유실된 준비 결과의 재입수를 수정했다.
- 자원 생성 뒤 컨텍스트 세대를 증가시켜 새 강·호수 자원에 이전 세대를 기록하던 순서를 수정했다.
- 관련 단위 162건, 변경된 시작 계약 1건, WebGL/Canvas 날짜 시나리오 2건, 시작 표시 시나리오 1건, 변경 JS lint, 생성물 `--check`, diff 공백 검사 통과.
- 앞선 전체 `startup-performance-contract` 파일 실행에서 발견한 기존 Proxy 스냅샷 소스 표식과 오래된 자료 URL 표식 실패 2건은 이번 자원 정책과 분리했다. 최종에는 변경된 계약 1건만 실행했다. 기존 원격 CI·라이브 사이트 상태를 이번 로컬 결과로 대신하지 않는다.
- 전체 테스트, C++ 빌드, GIS 검증, main 병합, 원격 앱 푸시, 웹 배포, 앱 패키징은 실행하지 않았다. 캐시된 네이티브 실행 파일에 현재 JS/CSS 개발 자산을 연결했다.

## 보관과 한계

검사 로그는 선택한 검증의 원본 출력이다. 보고서 게시·원격 검증은 작업 완료 단계에서 이 범위에만 수행한다. 기존 데이터·저장 형식·지형 품질·국가와 육지의 품질 연동은 유지했다. 동일성을 입증하지 못하는 형상이나 퇴출된 자원에는 재사용을 강제하지 않는다.
