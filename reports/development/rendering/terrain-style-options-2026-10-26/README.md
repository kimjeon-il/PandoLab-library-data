# 지형 표시 기본 시안 두 가지와 혼합형

2026-10-26. 사용자 요청: 색채·흑백에서 밋밋한 고저차를 개선할 두 시안을 비교한다. 앱 적용·main 통합·배포는 하지 않는다.

## 비교 이미지

- [1안: 대비 강화](option-a.png): 현재 색감을 유지하고 색·명암 대비를 확대한다. 음영의 평면 기준값에서 편차를 2배, RGB 중간값 대비를 1.22배 적용했다. 고도별 새 색상은 넣지 않았다.
- [2안: 고도 구분과 입체 음영](option-b.png): 음영 계산의 경사 성분만 2배 강조하고, 북서/서/북/남서 방향의 조명을 0.55/0.20/0.15/0.10으로 혼합했다. 기본 밝기 0.27, 조명 성분 0.73, 평면 기준의 편차 1.3배를 사용했다. 색채는 기존 바탕색 40%와 고도별 색 60%를 혼합하고, 흑백은 0~6000m에 따라 기본 명도를 0.58~0.88로 구분했다. 수치는 시안용이며 확정 사양이 아니다.
- [3안: 혼합형](option-c.png): 사용자의 추가 요청으로 기존 바탕색 75%와 고도색 25%를 혼합했다. 경사 강조를 1.6배로 낮추고, 조명 방향 가중치는 0.70/0.12/0.10/0.08로 조정했다. 기본 밝기 0.32, 조명 성분 0.68, 음영 편차 1.3배, 바탕색 대비 1.08배를 사용했다. 흑백 고도 명도는 0.68~0.87로 좁혀 2안보다 밝고 완만하게 고원을 구분한다. 1안의 익숙한 색감과 2안의 입체 표현 사이를 탐색하는 시안이다.
- 현재 비교 기준: [색채](current-physical.png), [흑백](current-political.png).

2안의 밝은 고도색은 고도 표현이며 실제 적설·빙하 분포를 새로 판정한 것이 아니다. 높이의 실제 수치·좌표·정치체·국경 자료는 변경하지 않았다. 산맥의 형태와 평야·고원의 높이 차이를 함께 읽는 목적에는 2안을 권하지만, 사용자의 시각적 선택이 필요하다.

## 생성과 확인

- 기존 `D:/dev/worktrees/ui`와 그 작업트리의 Viewer 개발 서버 `127.0.0.1:4173`을 재사용했다. health 응답의 root/product/error를 확인했다. 새 서버·작업트리·빌드 디렉터리·전체 자료 복사본은 만들지 않았다.
- 앱 작업 커밋 기준 `3d5744b81758c4a0d4502e205b30c44cdc6109af`, 자료 핀 `68380579a7c7a1bd8ec97683b7517502c1389c3c`.
- `render-options.mjs`가 별도의 headless Edge/D3D11에서 셰이더 모듈 응답만 변경한다. 앱 소스 파일과 사용자의 브라우저 탭은 변경하지 않는다.
- 동일 영역: 히말라야·티베트·인도 저지대, globe 회전 `[-85,-31,0]`, 배율 5.5, viewport 1000×760, DPR 1. 정치체·지명 등의 표시를 꺼 지형끼리 비교했다.
- 시안 A/B 모두 색채·흑백 각각 WebGL2, 세부 음영 활성, 목표 LOD 4, 타일 17/17, `terrainReady=true` 확인 후 캡처했다. 페이지 실행·셰이더 컴파일 오류 없음. `render-evidence.json`에 실제 값과 카메라를 기록했다.
- 혼합형 C도 같은 카메라·해상도·타일 17/17·세부 음영·준비 완료를 확인했다. 실행 오류 없음. `render-evidence-c.json`과 `c-physical.png`, `c-political.png`에 원본 캡처와 실행 값을 보존했다. A/B 이미지는 덮어쓰거나 다시 만들지 않았다.
- 초기 시안의 GLSL 예약어 변수명 충돌을 수정한 뒤 A/B를 다시 렌더링했다. 실패한 시안은 최종 이미지에 포함하지 않았다.
- 원본 캡처 `a-physical.png`, `a-political.png`, `b-physical.png`, `b-political.png`를 실제 앱 렌더러에서 얻고, 두 패널 이미지는 메모리의 HTML로 배치해 캡처했다. 생성형 이미지나 가상의 지형을 사용하지 않았다.
- 두 패널 이미지의 글자·크롭·색채와 흑백 차이를 직접 확인했다. 제품 기능 구현이 아닌 시안이므로 전체 테스트·GIS 재생성·네이티브 빌드는 실행하지 않았다. WebGL 시각 시안만 검토했으며 Canvas·기기 검증을 완료했다고 주장하지 않는다.
- 실행 후 headless 브라우저를 닫았다. 남은 파일은 사용자가 선택할 시안, 비교 기준, 재현 설정과 실행 증거이며 모두 이 보고서 범위 안에 있다. 기존 개발 서버는 유지했다.


## 보관 상태

기본 두 시안을 작성한 당시 선택 범위 `reports/development/rendering/terrain-style-options-2026-10-26`에 대해 `--publish-reports`를 두 차례 실행했지만, 다른 objects 작업이 가진 공유 라이브러리 잠금 때문에 저장 시작 전에 실패했다. 확인한 잠금 소유자는 PID 25688, checkout `.pando-worktrees/objects`였다. 해당 프로세스·잠금을 종료하거나 제거하지 않았다. 당시 시안 11개 파일 약 7.4MiB는 독립 편집본에 보존했고 원격 보관은 미완료였다. 혼합형까지 작성한 뒤 해당 작업의 잠금이 해제된 것을 확인했으며, 완료된 시안 범위만 다시 게시한다. 검증한 라이브러리 revision과 파일 수는 게시·재확인 명령의 완료 응답으로 기록한다.
