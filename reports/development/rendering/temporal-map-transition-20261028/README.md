## 대상과 원인

세계지도 자료 보기의 날짜 변경을 대상으로 한다. 프로젝트에 날짜 이동을 추가하지 않았다.
기존 렌더러는 새 장면 등록·메시 준비 시작 시 프로젝트 표시 차단을 해제했다. 이전 프레임 보존 조건이 이 차단 여부와 빈 장면에 묶여 있어, 아직 국가가 없는 새 배경이 이전 지도를 덮을 수 있었다.

## 반영한 코드

- builtin 시점 변경의 temporal 전환 목적과 요청 유효성·표시 완료 콜백을 기존 프로젝트 교체 경로로 전달한다. 실패 복구도 같은 보존 경계를 사용한다.
- WebGL은 기존 scene-color-cache의 staging에 준비한다. 국가·공유 경계·물리 육지와 켜진 지형이 준비된 후보만 공개한다. 합성 실패 시 이전 active/staging 소유권을 복구한다. 해상도 한계 안내만으로 준비 완료를 인정하지 않는다.
- Canvas2D는 렌더러 내부 임시 canvas에 그린 뒤 복사한다. Canvas Worker는 현재 요청·프로젝트·컨텍스트·프레임의 실제 bitmap 완료를 확인한다. Worker 오류 때 표시 canvas를 즉시 교체하지 않는다.
- 기존 렌더 조정자가 보존 중 이름·선택·화면 부착 표시를 보류하고, 완료 프레임에서 함께 반영한다. 날짜의 canonical 표시 확정은 해당 프레임 공개 콜백에 연결했다.
- 래스터 전용 소스의 URL을 DEM 안내로 다시 전달하던 Canvas Worker 연결 오류도 수정했다. 미리보기/정밀 배율 규칙과 공통 자료 의존성 재사용은 유지한다.
- 별도 전역 전환 관리자, 프로젝트 사본, 저장 형식, GIS 산출물은 추가하지 않았다.

## 실제 실행한 집중 검사

- 관련 단위 검사 6개 파일: 64개 통과, 약 0.62초. 프로젝트 교체·rollback·현재 요청 판정, 달력의 프레임 확정, 렌더 조정자의 표시 보류, 합성 실패의 이전 캐시 복구, Worker 완료 식별자를 확인했다.
- 변경된 소스·검사 파일 ESLint와 git diff --check 통과.
- 기존 생성기로 공통 프런트엔드 1,107개 자산을 갱신했다. 입력 SHA-256은 f68a771ab33d086446f846111ee15b783abd98766b877337a039d03f4484ce14이며 고정 개발 캐시가 현재 소스를 제공한다. 설치 패키지는 만들지 않았다.
- tests/browser/temporal-map-presentation.spec.mjs: WebGL, Canvas2D, Canvas Worker 3개 시나리오 통과. 최종 실행의 개별 시간은 약 57.8초/42.0초/21.0초이며 고정 성능 보장이 아니다.
- 960×640 브라우저에서 다음 국가 준비를 의도적으로 지연했다. 지도 자체는 960×592이다. 일반 WebGL 컨텍스트 옵션을 그대로 사용하고, DOM 안내·날짜창을 제외한 실제 브라우저 합성 이미지를 비교했다. 세 경로 모두 이전/대기 픽셀 차이가 0이었고 이름·날짜도 유지됐다. 완료 후 새 지도와 날짜가 변경됐다.
- WebGL 같은 시나리오 안에서 계산 실패 후 이전 지도·날짜 복구, 재시도, 연속 두 요청 중 마지막 시점만 공개, 동일 시점 재조회 시 메시 재계산 없는 재사용을 확인했다.
- 초기 검사에서 발견한 Worker 단위 fixture의 누락된 생성 자산은 현재 canonical resource-update-policy 소스를 실제 생성기와 같은 esbuild 방식으로 평가하도록 수정했다. 검사를 생략하거나 실패 기대값을 약화하지 않았다.

## 한계와 미실행 범위

실제 Windows WebView 개발 실행은 네이티브 미커밋 입력 보호 규칙으로 시작 전에 중단됐다. 오류에 표시된 대상은 native-contract.mjs, native-producer.mjs, icon.ico, icon.png이며 다른 채팅 작업으로 보존했다. 따라서 브라우저의 Canvas 검증을 실제 WebView 검증으로 보고하지 않는다. 실제 사용자 사용성 검증도 실행하지 않았다.

전체 테스트·C++ 빌드·GIS 검증·GIS 재생성은 실행하지 않았다. 앱 저장소 main 반영·원격 푸시·배포·앱 패키징도 수행하지 않았다. 초기 진입 순서는 기존 방식을 유지하며 본 변경의 공개 보류는 시점 이동에 한정된다.

## 첨부

before-*.png와 temporal-*.png는 각 렌더 경로의 전환 전/완료 후 화면이다. 대기 중 픽셀 동일성은 위 집중 검사의 실제 합성 이미지 비교 결과로 확인했다. 애플리케이션 소스와 테스트가 재현 절차의 원본이다.
