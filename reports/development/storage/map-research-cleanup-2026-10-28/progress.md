# 지도 조사자료 정리 실행 기록

- 완료: 원격 기존 GIS/자료 정리를 반영하고, 폐기 보고서 425개를 다섯 소유자 판본에서 제거했다. 다른 소련·카스피해 비공개 판본은 보존했다.
- 완료: 유지할 핵심 보고서 10개를 다섯 소유자에 반영하고 원문과 다른 보관 해시 3개를 수정했다.
- 완료: 앱 계획 문서의 역사 조사 기록 2건을 중앙 보고서로 분리·축약하고 원격 바이트를 확인한 뒤 원래 문서를 구현 제약과 링크로 정리했다.
- 완료: 명시적 삭제 게시·확인, 색인 밖 Git 원문 삭제, 현재 소련 보고서 경로 및 폐기 자료를 요구하던 CI를 수정했다. 관련 검사 16/16, ESLint, YAML 구문·범위 검사와 diff 검사가 통과했다.
- Ruling: .superpowers 임시 폴더 대신 중앙 보고서 편집본을 실행 기록의 단일 위치로 사용했다. 비용: 완료 보고서에 실행 증거가 함께 보관된다.
- Ruling: 이미 반영된 원격 정리를 다시 수행하지 않고 대상별로 대조했다. 운영 지도·자료 핀·기술 검사는 유지했다.
- Ruling: 다른 작업의 살아 있는 잠금은 기다렸다. 보고서 전용 작업은 지원되는 compact:false를 사용해 독립 압축 journal을 건드리지 않았다.
- 보류: 동시에 발생한 Git 압축 상태 변경에 대한 기존 복구 명령도 원본 pack 변경을 감지해 중단했다. 412MB의 설치/단계 pack·journal은 실제 Git 복구 소비자가 있어 보존하며 강제 삭제하지 않았다.
- 리뷰: 색인에 없는 Git 원문을 삭제할 수 없던 중요 지적은 재현 검사 RED→GREEN으로 수정했다. 테스트명과 빈 디렉터리 상태의 경미한 차이는 기록만 남겼다.

- 후속 상태: 412MB는 삭제 대상. 이력 재작성과 보존 대조 완료. 물리 삭제는 자동 승인 검토 차단으로 미완료이며 앞선 복구 소비자 사유는 superseded 됨. 상세는 map-research-history-purge-2026-10-28 참조.
