사용자가 제보한 ① 처음 열 때 바다·육지·기타 요소가 따로 나타나는 현상과 ② 새 프로젝트 생성 중 흰 지도 화면을 조사했다. 제품 동작 코드·저장 형식·지도 자료는 수정하지 않았다. 작업용 보고서는 상설 UI 워크트리에 두며 기존 미완성 변경을 보존했다.
실제 배포 웹과 main을 제공하는 로컬 웹 편집기를 Windows Chromium/D3D11에서 실행했다. Windows WebView2 앱은 갱신한 실제 실행 파일과 기존 실행기를 사용했다. 별도 WebView 프로필을 환경 변수로 지정하고 실제 자식 프로세스의 `--user-data-dir`도 해당 증거 폴더인지 확인했다. 앱의 기존 사용자 프로젝트를 대상으로 생성 작업을 하지 않았다.
브라우저/WebView에서 WebGL draw, 준비 상태, 프로젝트 세대, 네트워크 완료, 긴 메인 스레드 작업과 화면을 기록했다. 로컬 편집기는 진단용 응답 치환으로 기존 함수 경계에 타임스탬프만 추가했다. 뒤의 대조 실험도 응답 치환이며 저장소 제품 소스 변경이 아니다. 시간은 계측한 이 PC의 단일 실행값으로, 일반적인 사용자 기기의 소요 시간 보장이 아니다. 앱 초기 수치는 진단용 재로딩이며 최초 프로세스 기동 시간과 구분한다.
