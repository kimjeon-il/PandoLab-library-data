# 보고서 완료 시 원문 보관·커밋·푸시 보장

> ID: DEV-REPORT-COMPLETION-20261025 · 상태: focused-verified / source-worktree-applied · 지도 반영: not-applicable
> 코드: Pando work/ui ba09f55f1523319f40fd749d02f66a6ca5666dfe; 기존 상설 작업공간 재사용.

원인: 경로 helper는 편집본만 반환하며 보관은 별도였다. --store는 --push가 없으면 로컬 커밋에서 끝나고 원격 원문 확인도 완료 조건이 아니었다.

기존 tools/library-data.mjs의 저장 구현을 재사용하는 --publish-reports와 --check-reports를 추가했다. 명시한 현재 브랜치의 보고서 범위만 공유 라이브러리 main에 보관·커밋·푸시하고 원격 보관 목록과 실제 원문의 SHA-256·길이를 확인한다. 런타임 준비·전체 복사·자료 핀 변경을 수행하지 않는다. 분리된 자료 작업트리의 비공개 런타임 이력은 공개하지 않는다.

범위 누락·빈 범위·잠금·dirty/diverged main·미공개 비보고서 이력·선택 범위 밖 대기 보고서·푸시 거부·원격 내용 불일치는 오류다. 같은 범위의 실패한 푸시만 기존 커밋으로 재시도한다. 원문·다른 범위·다른 작업트리·자료 핀을 보존한다. 파일 쓰기마다 자동 공개하는 감시기는 추가하지 않았다.

AGENTS.md, branch-policy, library-data 문서와 reports:publish/check 명령을 기존 5개 작업공간에 적용했다. 최종 증거를 수정한 뒤에도 완료 명령을 재실행하고 검증한 커밋·범위를 보고하도록 규정했다. 앱 main 통합·배포·다른 미완성 작업 공개의 승인은 포함하지 않는다.

검증: 미구현 상태에서 4개 RED 확인. 기존 library-data/report-paths를 포함한 관련 10개 통과. 독립 검토가 찾은 다른 범위의 대기 커밋 공개 문제를 추가 RED로 재현·수정한 뒤 최종 게시 테스트 4개 재통과. 관련 ESLint 및 변경 공백 검사 통과. 기존 미사용 import와 오류 cause 누락도 정리했다. 이번 보고서 자체를 새 명령으로 실제 게시·재검사한다. 전체 테스트·브라우저·네이티브 빌드·GIS 재생성은 실행하지 않는다.

소스는 다른 작업의 미커밋 저장공간·학습 변경과 함께 있어 임의로 커밋·푸시하지 않는다. 현재 작업본에 적용한 도구의 독립 변경은 [패치](source-change.patch), 새 회귀 테스트는 [테스트 원문](library-report-publication.test.mjs)에 보관한다. 다른 작업의 파일과 변경은 폐기하지 않았다.
