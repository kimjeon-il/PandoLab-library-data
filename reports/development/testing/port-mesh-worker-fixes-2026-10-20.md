[검사 자동화 구현 기록](check-automation-2026-10-19.md)에 미해결로 남긴 편집 포트 제한 실패와 WebGL `PL-MESH-PREPARE` 시간 초과를 수정했다. 기존 `work/ui`의 Tauri 권한 파일·CRLF 차이·과거 미추적 검증 자료를 보존했다. C++·WASM·지도 원본 좌표·프로젝트 형식·UI 설계는 변경하지 않았다.
기존 실패 검사와 실제 내장 지도 브라우저 흐름을 먼저 실행했다. 포트 구성 실패, 육지 자산 누락, 진행 중인 면 준비의 잘못된 시간 초과, 검사 연결 누락과 생성 자산 헤더 차이를 각각 실패하는 검사로 확인한 뒤 수정했다. 현재 생성 메타데이터 검사의 오래된 fixture가 실제 의존성을 제공하지 못하는 실패도 재현해 fixture를 갱신했다.
물리 육지 원본은 기존 `physical-land/v1/geometry.json.gz`다. 4,274개 polygon, 548,454개 좌표의 합성 지오메트리는 변경하지 않았다. 이를 기존 mesh 알고리즘 5로 준비하면 정점 1,026,976개·삼각형 1,501,543개가 된다. 로컬 Node에서 즉시 계산한 비용은 약 8.3초였으며, 브라우저에서는 다른 초기화·표시 작업과 같은 시간 제한을 사용하고 있었다.
새 자산은 압축 19,388,644 bytes, 해제 후 43,498,236 bytes다. 추가 다운로드·패키지 크기와 실행 중 계산 비용의 교환이며, 기존 무결성 검증·불변 캐시·배포 자산 수집 경로를 사용한다. 별도 렌더러·로더·캐시를 추가하지 않았다. full-world가 기존 manifest에서 자산을 수집하며, small-project는 기존 경량 자료 제한을 유지한다.
