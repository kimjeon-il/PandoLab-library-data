승인된 방향에 따라 웹 열람기는 지구본 전용, 앱 편집기는 기존 평면 전용으로 유지한다. 공통 평면 렌더러나 지도 자료는 삭제하지 않았다.
- 기존 제품 정책이 제품별 투영을 소유한다. 웹에서 명시적 평면 전환은 `PL-PRODUCT-PROJECTION`으로 거부한다. 카메라 복원은 기존 원자적 보기 상태 소유자에서 해당 제품의 투영으로 맞추며 중심 위치·실제 투영 크기를 변환한다. 프로젝트 데이터·이력을 수정하지 않는다.
- 초기 범위가 있는 파일도 웹에서는 지구본에 맞춘다. 날짜변경선을 넘는 범위의 중심을 정면으로 돌리고, 구면 각거리·가용 화면 크기로 확대율을 정한다. 반구 이상이거나 지평선에 닿는 넓은 범위는 전체 지구본을 유지한다. 앱의 평면 범위 맞춤은 유지한다.
- 투영법 메뉴·버튼·아이콘·전용 스타일·이벤트·설정 API와 포트를 제거했다. 상태 표시 갱신은 원래 상태 표시 소유자를 직접 호출한다. 초기 범위 맞춤·검색·전체 지도 보기·확대가 평면 전환을 요구하지 않는다.
- HTML 조각과 CSS 원본을 수정하고 기존 생성기로 웹/앱 HTML, CSS 묶음, 빌드 메타데이터와 영향받은 Worker 자산을 생성했다. 이전 캐시·Worker 자산 폴더는 자동 삭제하지 않았다.
- 앞선 초기 로딩·프로젝트 교체 중 화면 보존 수정은 유지했다. 새 프로젝트 시간 기능·저장 호환 계층·별도 보기 상태는 추가하지 않았다.
브라우저에서 최초 실행 시 지구본, 투영 메뉴 없음, 명시적 평면 전환 거부를 확인했다. 실제 viewer의 카메라 연결에 평면 스냅샷을 넣어 지구본 정면 중심으로 복원되는지도 확인했다. 이어 현행 인코더가 만든 초기 범위 지정 GeoPackage를 실제 파일 입력으로 열고, 정면 중심·확대, 검색 결과 선택, 전체 지도 보기를 검사했다. 1440×900에서 390×844로 변경하고 드래그 회전·CDP의 두 손가락 터치 확대를 실행해 지구본 유지와 프로젝트 상태 불변, 페이지 오류 0개를 확인했다. CDP 터치는 모바일 실기기 검증과 구분한다.
