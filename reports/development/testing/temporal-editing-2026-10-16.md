선택한 자료의 기준일과 편집 지도의 적용 월을 분리한다. 1991년 자료를 2012년 지도에 넣으면 생성 시점은 2012년이며 자료 기준일은 출처로 보존한다. 이름·국기·색상은 각 속성의 다음 명시적 변경까지 적용한다. 저장본의 `editorState.lastViewedMonth`는 재개 위치이며 문서 Undo/dirty 상태의 소유자가 아니다.
앱의 향후 방향은 앱에 포함한 Web UI·WebGL·Worker·WASM의 공유다. 이번 변경은 공통 계산과 현재 Qt 어댑터에 한정하며 앱 실행 틀 전환의 검증 결과로 해석하지 않는다.
전체 테스트를 실행하지 않았다. 변경된 타임라인·지명·라이브러리 계약과 해당 사용자 흐름만 확인한다.
- 부모 관계 변경은 같은 C++ 소유자가 구조·기간·지리 포함을 검증한다. 초기 원본 관계의 입장은 명시적인 `SourceAdmission` 문맥으로 구분하며 사용자 명령은 엄격한 검증을 유지한다. 국가 ID 예외나 허용 오차 확장은 없다.
- 역사 자료는 이용 가능·형상 공백·명시적 부재·미확인으로 구분한다. 가까운 시점의 형상으로 대체하지 않는다.
- 언어별 이름 근거가 없는 과거 지명은 `(현)서울`처럼 표시한다. 명칭 근거가 없다는 이유로 도시를 역사적으로 없었던 것으로 처리하지 않는다.
- Qt의 파일 재열기와 자동저장 복구가 같은 월 복원 규칙을 사용한다. Undo/Redo의 선택 해제는 기존 공통 계약이며 관계 변경의 성공 여부는 재선택 후 실제 모델로 검사한다.
- 이전 페이지 종료 중 남은 자동저장·지명 작업은 해당 소유자가 실제로 취소한다. 활성 문서의 기술 오류를 가리는 처리가 아니며, 재열기·종료 때 잘못된 미로드/저장 실패 로그가 남지 않는 것을 최종 브라우저 검사로 확인했다.
