## 대상과 기준일

사용자의 “최대한 다양한 지도로 계속 학습” 요청에 따라 실제 고지도 원본의 표현 조건을 확장하고 기존 학습 체크포인트에서 계속 학습했다. 이번 회차는 최대 96개 원본을 목표로, 확인한 권리와 유효한 정답 조건을 통과하는 실제 원본을 확보하는 범위다. 무기한 무인 학습이나 새 모델의 제품 배포는 아니다. 지도 원본의 발행일·언어·문자·제작 계열을 확인하지 못한 경우 미상으로 유지했다.

## 근거와 방법

- [Semap 고정 판본](https://zenodo.org/records/19048095), Petitpierre, Gomez Donoso, Kriesel, EPFL. 라벨은 CC BY 4.0, 원 지도 재사용 조건은 저자가 제공한 `corpus/semap-diverse/sources/license_images.md`를 따른다. 독립적인 법률 검토를 완료했다는 뜻은 아니다. 비상업·제한·불명확한 기관은 사용하지 않았다.
- [원 논문](https://arxiv.org/html/2603.05037v1)의 도로망 범주는 길·광장·보행로·다리 등을 포함한다. 이 면형 정답은 USGS의 가는 교통 선형과 같지 않다. 수계와 도로의 보조 감독으로만 사용하며 국제 경계 성능 개선으로 해석하지 않는다.
- 저자의 실제 이미지 train 분할만 사용했다. 합성 이미지, 저자의 validation/test 자료, 단순 회전·재색칠을 새 원본으로 세지 않았다. 같은 기관·문서의 여러 패치와 페이지는 원본 1개로 센다. 먼저 정답을 읽어 감독 픽셀 3% 이상, 양성 수계/교통 픽셀 0.5% 이상을 요구했다. 첫 후보가 비어 있어도 다른 후보를 확인하며, 유효 후보를 얻은 뒤에만 그 원본을 선택 완료로 센다.
- 기존 수집 폴더와 불변 원본·라벨을 재사용하고 `corpus.expanded.training.json`만 추가했다. 확장 목록은 실제 원본 **82개 / 9개 기관 / 감독 타일 318개**다. 기존 USGS 5장 / 150개 타일을 더해 **총 87개 원본 / 468개 타일**을 사용한다. 이전 고지도 목록은 수집 24개 중 실제 감독 원본 17개 / 65개 타일이었다.
- 기관별 원본: Berkeley 4, Bordeaux Montaigne 5, Boston Leventhal 8, NYPL 12, Leiden 12, WWU Münster 5, e-rara 12, Library of Congress 12, Princeton 12. 기관 수를 독립 제작 계열 수로 해석하지 않는다. 일부 후보 기관에는 이번 조건을 통과하는 자료가 없었다.
- [접촉 시트](../corpus/semap-diverse/expanded-source-diversity.jpg)에서 판화·착색 지도·시가지도·지형도·낡은 스캔 등 서로 다른 표현을 확인했다. 입력 chroma 기준으로는 전부 color 82개다. 육안으로 단색 잉크/세피아 계열이 있어도 별도 순수 흑백 평가군을 검증했다고 주장하지 않는다. 한중일·아랍어·페르시아어·우르두어·그리스어 검증 범위도 확인되지 않았다.
- 고지도는 `hydro`와 `transport`만 감독한다. 명시적인 built/non-built 픽셀을 두 채널의 음성 근거로 쓰고 background/contours는 무시했다. 국경·행정경계·해안·문자·도곽의 미상 픽셀을 음성으로 바꾸지 않았다. 기존 USGS 감독은 유지하며 해안 채널은 계속 미학습이다.
- HTTP Range로 선택한 원본 멤버만 받았다. 응답 범위·길이·ZIP 멤버 CRC/크기·로컬 SHA256을 검증한다. 짧게 읽힌 응답은 거부했으며 128KiB 이하 전송, 완전 읽기, 제한된 재시도로 처리했다. 전체 대형 ZIP의 MD5를 검증했다는 주장은 하지 않는다. 작은 권리표·README·분할 ZIP은 고정 길이/MD5도 확인했다.
- 검증기는 원본 PNG에서 현재 의미 마스크와 유효성 마스크를 다시 계산한다. 마스크와 그 SHA256을 함께 바꿔도 원본 변환과 다르면 거부한다. 과거 생성 코드 해시는 불변 출처 기록으로 보존하고 최신 선택 스크립트와 같은 해시를 요구하지 않는다. 원본과 모든 출처 신원을 동시에 바꾸는 공격을 검출한다고 주장하지 않는다.

학습은 기존 GTX1650 4GB와 고정 Python 환경을 사용했다. 초기화는 실제 `models/diverse-v1/boundary.pt`이며 SHA256은 `305c0c63a3942f55f2dc8ca0a91698b6eff7b16d5e5df35d4c0e091cd4a53fef`이다. 6 epoch, batch 1, AdamW LR 0.00003, encoder 동결 0 epoch, CUDA AMP로 실행했다. 데이터/모델 seed 20261022, 샘플링 seed 20261023이다. 두 코퍼스에 각각 epoch당 234개 타일을 할당하고 원본마다 최소 1개를 방문한 뒤 원본 균등 추출로 추가 샘플을 뽑는다. 큰 지도 한 장의 타일 수가 다른 원본을 압도하지 않게 했다. 성공 갱신·시도 배치·AMP 건너뛰기는 분리 기록한다.

이 모델을 v1보다 전반적으로 우수하다고 판단하지 않는다. 새 자료에서 수계 fitting은 개선됐으나 교통과 기존 자료의 일부 지표는 후퇴했다. 기준값을 사후 조정해 결과를 숨기거나 기본 모델로 승격하지 않는다. 서로 다른 정답 범주와 독립 평가 자료를 보완한 다음 회차가 필요하다.

고정 검사: 코퍼스·출처·변환 Python 32개, 모델·샘플링·AMP Python 7개, 패키지·타일·승인 게이트 Node 3개를 실행해 모두 통과했다. 빈 첫 패치 때문에 원본을 누락하던 문제와 극단적인 원본 수에서 코퍼스 할당량이 달라지던 문제는 실패 재현 후 수정하고 회귀 검사했다. 남겨둔 경미한 코드 검토 지적은 없다.

모든 자료는 train이다. 학습 손실과 동일 타일 전후 비교는 fitting 진단이며 독립 정확도·일반화 성능은 아니다. 실제 국경·행정경계의 다양한 원본 라벨, 문자권별 정답, 독립 제작 계열 평가, 해안 정답이 남아 있다. Windows WebView2·Android의 새 모델 성능, 8MP 전체 처리 메모리/180초 목표, 역사적 형상 정확도 및 0.5 CSS px 기준은 이번 회차에서 실행하지 않았다.

## 데이터 반영과 판본

가중치·원본·라벨·진단은 외부 자료 저장소에 보관하고 앱 Git에는 도구·계약·테스트·개발 명세만 둔다. `trainingOnly=true`, `evaluationStatus=pending`, `releaseApproved=false`를 유지한다. 활성 모델 경로에 미승인 모델을 넣거나 국가·행정구역 형상을 바꾸지 않는다.

정리: 끝난 수집 작업의 빌드 로그 4개를 원문과 SHA256이 같은 외부 증거로 이전한 뒤 중복 빌드 사본만 삭제했다. 제거 파일 총 35,090 bytes이며 목록은 `models/diverse-v2/acquisition-evidence.json`이다. 원본 지도·정답·재현 입력·체크포인트·관련 없는 미추적 Worker 파일과 상설 워크트리는 보존했다. 검사용 로컬 서버는 검사 후 종료했다.

이 보고서는 [첫 실제 학습 회차](trained-model-2026-10-23.md)의 후속이다. 이전 수치와 실행 기록은 당시 증거로 보존한다. 현재 전체 자동 분석 계획은 미완료이며 이번 모델은 독립 평가와 기기 검증 전 실험 모델이다.
