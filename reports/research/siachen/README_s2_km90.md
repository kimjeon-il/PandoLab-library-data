# km90 Saltoro optical review

2025/2026 Sentinel-2 L2A, acquisitions pinned in siachen_s2_optical_comparison.json. OSM line is a non-surveyed approximation. Original DEM peaks capped to ±900m should NOT be treated as actual ridge positions. Satellite scenes are snow covered and do not establish field troop locations, control, or internationally agreed borders.

Output: 2025+2026 georeferenced PNG crops, input-source JSON, 6-station GeoJSON points.
Licensing: © Copernicus Sentinel data; © OpenStreetMap contributors (ODbL); © ESA/Airbus Copernicus GLO-30.
