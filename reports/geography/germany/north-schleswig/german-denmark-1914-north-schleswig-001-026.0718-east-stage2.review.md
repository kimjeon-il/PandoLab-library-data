# 1914년 독일제국–덴마크 국경 2차: Hvidding 0718 동쪽 절반

> 압축 열람본: 아래는 도입부와 항목 목록의 발췌이며 전체 결론을 대신하지 않습니다.

**상태: 1:25,000 원본 지도 중첩 및 육안 대조 완료(overlay-reviewed) / 역사 국경선 자체 확정은 보류(provisional).**
- **대상**: 도엽 0718 Hvidding 동쪽 절반, 약 5.94054 km.
- **시작 좌표**: (8.750261798203894, 55.27444861174032) — 1차 작업 종료점.
- **종료 좌표**: (8.833333333333332, 55.27205685739951) — 0719 Spandet 도엽과의 접점.
- **역사 기준일**: 1914-07-31.
- **사료**: [Messtischblatt 34 Hvidding](https://www.deutschefotothek.de/documents/obj/71051522), 목록상 1878년 측량 / 1880년 발행, SLUB 원본 WMS ID 10006008.
- **검증 규칙**: [역사적 국경·해안선 복원 공통 정책](https://github.com/kimjeon-il/Pando/blob/7edbf231501cad51346dc5d2d626ba8acb31379b/docs/historical-border-reconstruction-policy.md). 2560 CSS px 화면, 평면 최대 확대 64, 정밀화 종료 목표 0.5 CSS px. 역사적 귀속·연대·하천·위상 문제는 화면 크기와 관계없이 필수 검증.
- **작업 브랜치**: 웹·앱 work/gis. main 미변경.
기존 후보선을 1880년 Hvidding 원본 지도에 중첩하여 전체 이미지 1장·상세 이미지 2장을 작성했다. 0719 Spandet 원본을 같은 지리 범위에서 중첩한 접합부 이미지도 1장 작성했다.
- **서쪽 상세 화면**: 국경 표식 약 **8~10번** 및 **8번 부근의 뚜렷한 북동 방향 꺾임**을 현행 교구 기반 후보선이 대체로 따른다.
- **동쪽 상세 화면**: 국경 표식 **10~12번**, 완만한 동남 방향 진행, 도로 교차부에서 기존 후보선과 뚜렷한 경로 불일치가 보이지 않는다.
- **도엽 경계 부분**: **12~13번** 부근에서 0718 Hvidding과 0719 Spandet 지형도상의 역사 국경 진행 방향이 대체로 자연스럽게 연결되며, 현재 후보선에도 끊김이 없다.
- **육안 판정**: 검토한 해상도에서 **대규모 경계선 경로 오류를 발견하지 못함**. 역사 지도에 명시된 정확한 경계 선형을 독립적으로 벡터화하지 않았으므로, **역사적 최대 편차가 0.5 CSS px 이내라고 판정하지 않음**.
