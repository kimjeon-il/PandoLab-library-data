# 독일제국–덴마크 1914년 국경: Hårup 곡류·Gels Å/Flads Å 합류점 후속 검증

> 압축 열람본: 아래는 도입부와 항목 목록의 발췌이며 전체 결론을 대신하지 않습니다.

**판정: 1878년 지도에서 화면상 의미 있는 일부 하천 차이를 확인. 1914년 역사적 국경선 수정은 미승인. 마스터 및 26번 이후 임시 경계선은 보존.**
- 기준일 **1914-07-31**.
- 1878년 프로이센 1:25,000 [Hügum 제21도엽](https://www.deutschefotothek.de/documents/obj/71051510) (SLUB WMS ID **10006020**).
- 대조 대상: 0619 Hügum의 현대 교구·수로 기반 임시 국경선 중 **Hårup 부근 물굽이** 및 **Gels Å·Flads Å 합류점** 두 곳만.
- [GIS 공통 규칙](https://github.com/kimjeon-il/Pando/blob/7edbf231501cad51346dc5d2d626ba8acb31379b/docs/historical-border-reconstruction-policy.md): 웹 평면지도 최대 확대 **flatZoom64**, 지도 콘텐츠 **2560 CSS px**, 화면 차이 **0.5 CSS px**. 국경 시점·하천 규칙·귀속·연결 오류는 이 기준의 예외.
- **0.5 CSS px에 대응하는 각도 차이 0.0010986328125°**를 화면상 띠로 표시. 이 띠는 **실제 1914년 역사 선형을 따서 측정한 Hausdorff 오차가 아님**.
- [성공한 GitHub Actions 지도 대조](https://github.com/kimjeon-il/Pando/actions/runs/37822505181). 아티팩트: **north-schleswig-hugum-1878-two-hotspots**, 원본·중첩 JPG 두 쌍(7일 후 만료). 저작권 검토 없이 스캔을 Git 저장소에 복제하지 않음.
- 원천·화면 메타데이터: `german-denmark-1914-north-schleswig-001-026.0619-hugum-stage4.hotspots.json`.
- 재현 코드: `tools/review_north_schleswig_1914_hugum_hotspots.py`.
화면에 **붉은색 현대 후보선**과 **노란색 ±0.5 CSS px 허용 범위**를 표시해 1878년 지형도의 하천 획과 비교했다.
- 역사 도엽의 강 유로는 현대 후보선과 전반적인 동서 흐름을 공유한다.
- **큰 물굽이 한 곳 이상에서는 1878년 하천의 검정 선형이 허용 띠 바깥으로 보이거나 현대 후보선이 옛 물굽이와 다른 방향으로 진행한다.** 단순한 수 m 미세 굴곡으로 치부할 수 없으므로 잠재적 위치 오류로 유지한다.
