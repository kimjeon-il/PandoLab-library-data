## 범위와 근거

2026-10-23 조건 확장 모델의 성긴 아시아 감독을 보강한다. 원본은 동일한 CIA 세계지도2021·CIA 아시아2013·NRCan 캐나다 컬러/흑백으로, 원본 그룹3개·입력 판본4개다. 원본·출처·권리·연대는 [기존 기록](macro-conditions-training-2026-10-23.md)을 따른다. 새로운 독립 지도나 비라틴/역사 평가 자료를 추가한 작업이 아니다.

기존 아시아 반경2 정답은 전체1526 양성 픽셀뿐이었다. 동일 원본에서 반경3=18793, 반경4=39681을 측정했다. 반경4는 source-derived-weak 감독이며, 전체 지도 및 카자흐스탄·러시아·몽골 원본 픽셀 크롭을 육안 확인했다. 독립 정답과의 정확도 측정은 아니다. 좁은 수역 사이 오접속 가능성, 같은 색 경계 누락과 기존 문자/분쟁 지역 제외는 남는다. 감독 유효 픽셀은886503에서784450으로 감소하므로 양성 증가를 전체 정답의 완전성으로 해석하지 않는다.

원본 PDF·이미지·기존 라벨을 복사하거나 덮어쓰지 않고 별도 metadata recipe와 mask/annotation을 생성한다. 원래 familyId·editionId·duplicateGroup과 출처·권리는 변경할 수 없다. 기존37개 자료와 macro-v2 가중치의 SHA256을 보존 기록으로 대조한다.

## 검증과 한계

새 API 미지원 실패를 먼저 재현한 뒤23개 macro/corpus/source Python·9개 model Python·4개 Node 검사가 통과했다. 실제 새4판본 코퍼스를 재생성·소스 재검증했으며 이전37개 자료가 바이트 단위로 동일하다. 실제 제품 UI와 Windows WebView2/Android 전체 흐름은 이 작업에서 검증하지 않는다. 모델은 독립 평가 전 trainingOnly/pending이며 releaseApproved=false, 활성 앱 모델에 적용하지 않는다.

신규 코드와 최종 가중치/진단은 별도 읽기 전용 검토를 거쳤으며 중요/미해결 사소 지적은 없다. 검토자는 소스37개·초기화 파일3개의 보존 해시, 코퍼스 fingerprint, PT/ONNX 해시 및6개 수치 행을 별도로 대조했다. 독립 정확도·전체 기기 성능은 판단하지 않았다. 보관 검증은 [archive-verification.json](models/macro-v3/archive-verification.json)에 실제 파일 바이트 비교·비대상 자료 유지·런타임 핀 유지 결과로 기록한다.
