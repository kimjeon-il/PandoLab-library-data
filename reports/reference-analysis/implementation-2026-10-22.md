## 대상과 기준일

앱 내부 오프라인 OCR·자동 정합·경계 의미 분류·공유 경계망·새 일반 객체 생성을 위한 개발 체크포인트다. 역사 귀속 확정이나 실제 국가 경계 데이터 반영이 아니다. 이후 사용자 요청으로 현대·고대 그리스어 ell/grc를 포함했다. 추가 추천 언어팩은 아직 설치하지 않았다.

## 근거와 방법

- 실제 OCR 원본: `tools/historical-library/sources/korea/ibs017-1962-map.jpg`, SHA256 `23ab23c7a8d16782038ca237dbff9f5e7b7a2123286af9c03a37dd0e7bcbf844`, 852×675. IBS17, 1962-06-29: https://library.law.fsu.edu/Digital-Collections/LimitsinSeas/pdf/ibs017.pdf . 지도에는 서로 다른 시점의 분쟁선과 범례가 있어 단일 시점 경계 정답으로 확정하지 않았다. 앱 재배포용 학습자료 권리는 별도 검토가 필요하다.
- 독일 원자료 출처: SLUB Kartenforum WMS https://wms.kartenforum.slub-dresden.de/map/10006008 , `df_dk_0010001_0718`, https://www.deutschefotothek.de/documents/obj/71051522 . 기존 보고서의 발행/개정 시점 혼동과 자료 권리는 해결하지 않았다. 기존 현대 교구 기반 예비 선형을 역사 경계 정답으로 사용하지 않았다.
- 원자료 후보 3개 중 나머지 AAS PDF와 페이지 이미지는 문서 후보이며 지도 학습자료로 판정하지 않았다. 39개 인벤토리 항목은 출처 참조를 포함한 목록이며 39개 학습 지도가 아니다. 현재 검토된 경계 라벨/독립 확인점/학습 완료 모델은 없다.
- Tesseract.js 7.0.0, ONNX Runtime Web 1.30.0, tessdata_fast `87416418657359cb625c412a48b6e1d6d41c29bd`로 고정했다. 로컬 Worker·WASM·언어팩 17개(OSD 포함), 버전·해시·라이선스를 생성 도구가 기록한다. Apache/MIT 라이선스 원문은 코드 런타임 자산에 포함한다.

## 확인 결과와 한계

기존 컨트롤러가 유일한 분석/검토 상태를 소유한다. 전용 Worker는 기존 RPC·스케줄러를 사용한다. 전역 지명 검색은 현재 지도 화면과 독립적이며 동명 후보를 유지한다. 자동 추천에 최소 6개 대응·20% 분포·원본 픽셀 교차검증 P95 8px·격자 Jacobian 검사를 적용했다. 이 수치 검사와 테스트 통과가 실제 지역 선택률 95%를 증명하지는 않는다.

Core는 의미 마스크에서 공유 경계선과 닫힌 면·구멍을 만들고, 비선형 투영에서 중간점을 세분화한다. 날짜변경선 분할을 사용한다. 선택 객체는 기존 일반 객체 서비스의 단일 명령으로 생성한다. 실제 Core 객체 생성과 한 번의 Undo/Redo를 검사했다. 추론 모형을 대체한 테스트 데이터는 모델 정확도 증거가 아니다.

실제 보관 지도에 대한 OCR을 일반 실행과 전용 Worker 양쪽에서 실행해 제목 문자를 확인했다. 외부 요청은 0건이었다. 브라우저 검사는 desktop 1440×900 및 mobile 390×844 취소/늦은 결과 방어와 실제 OCR 두 건, 모델 인터페이스 검사까지 총 5건이 통과했다. 모델 인터페이스 검사는 고정 빌드 캐시에 만든 미학습 진단용 ONNX가 실제 WASM에서 [1,7,512,512] 유한값을 반환하는지만 확인했다. 이 가중치는 배포·학습 완료 모델로 사용하지 않는다. 휴대폰 브라우저 검사는 Android 앱 편집 또는 가로 화면 기기 검증을 대체하지 않는다.

학습 코드는 MobileNetV3/U-Net, 전체 문맥/타일 입력, 다중 의미 채널, BCE/Dice/연결성 손실, 계열·판본 분리, 원본 전체 도엽의 겹침 결합과 `max(2px, 원본 선폭/2)` 유클리드 거리 평가를 제공한다. 실제 지도 라벨 학습·ONNX 정확도·문자권별 성능 검사는 실행하지 않았다. 미학습/미검증 가중치는 앱에서 거절한다.

남은 구현: 방향·도엽·범례·삽입도 분리, 격자 좌표 기준점, 세로쓰기 보완, 짧은 점선 틈 연결, 분기/연결 편집 및 Live-Wire 추출망 수정. 남은 검증: 전체 지도군 학습·지역/경계 목표, 실제 Windows WebView2·Android 오프라인, 8MP 180초/384MiB, 실제 앱 생성→Undo/Redo→저장→재열기. 원본 16MP 및 투영 점 200만 개 제한은 초기 보호 한도이며 기기 성능 목표 달성을 뜻하지 않는다.

독립 역사 형상을 새로 디지털화하지 않았으므로 최대 확대·2560 CSS px·0.5 CSS px 정확도는 미검사다. 모델·자료·기기 검증과 위의 남은 구현 때문에 전체 계획을 완료로 판정하지 않는다.

관련 단위 검사 199개와 Python 검사 6개, 변경 JS의 ESLint가 통과했다. 전체 Worker 구조 검사에는 수정하지 않은 기존 `project-file-reader.js:11,18`의 직접 onmessage/postMessage 두 건이 남는다. HEAD의 같은 코드임을 확인했으며 이번 작업에서 예외·우회로 숨기지 않았다. 새 분석 Worker·client의 구조 검사에는 실패가 없다. source 및 배포 WASM 해시 검사도 통과했다. 로그는 unit.log, python.log, browser.log, worker-boundary.log, stage.log에 보관한다.

코드 검토에서 상태를 지우던 검토 버튼, TPS 선분의 곡선 손실, 연결선이 있는 중첩 폐곡선의 외부 면 누락을 재현해 수정했다. 각 회귀 검사는 실패를 확인한 뒤 통과했다.

## 데이터 반영

OCR 자료와 이 보고서만 별도 prefix로 보관한다. 같은 작업본의 관련 없는 DDR/GIS·다른 UI 보고서 변경은 포함하지 않는다. 원본과 기존 미완성 작업은 유지한다. 코드·자료의 원격 push, main 통합·배포 및 실제 앱 재빌드는 수행하지 않았다. 앱 staging 성공은 설치 앱 실행 증거가 아니다.
