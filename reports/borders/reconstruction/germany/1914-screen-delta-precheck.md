# 독일제국 1914년 해안선 — 1:1,000만 범위 요약

> 기존 조사 ID: GEO-DEU-007 / GEO-DEU-008 · 상태: 조사 범위 축소 / 역사적 해안 검증 미완료 · 정리: 2026-10-28

- 최종 표시 목표는 Natural Earth 1:10m이다. 국가 외곽·도서의 존재, 큰 간척 및 주요 하구·수계 연결처럼 표시·역사적 사건 설명에 의미 있는 변화를 먼저 다룬다.
- 기존 1914년 독일제국 작업 형상은 **현대 일반화 해안선을 잠정 재사용**한 영역이 있다. HistoGIS 후보선과 현대 선형의 픽셀 차이는 지도 일반화·수로 표현 차이 등을 포함하므로 1914년 간척 면적이나 시대별 역사적 위치오차로 해석하지 않는다.
- 돌라르트·야데만·북프리슬란트의 미세 제방, 세실리엔코크 같은 개별 소규모 간척, 1:25,000 WMS 도엽·미세 타일·고정밀 화면차 검증은 1:10m 표시 목적에 필요하지 않으므로 연구를 종료한다. 단, 주요 도시·도서·국경의 귀속 또는 큰 수역의 연결을 바꾸는 경우만 예외로 재선별한다.
- 당대 독립 해안 벡터·도엽을 사용한 완전한 1914년 해안선 복원은 **미실시**이며 0.5 CSS px 역사 정확도 통과를 주장하지 않는다. 사용 중인 국가 형상·기존 이벤트 시점·데이터 원본은 수정하지 않는다.
- 기존 사건·날짜 색인은 코드의 `tools/historical-library/sources/german-coastline/change-events.json` 및 관련 자료 원본을 기준으로 삼는다. 역사적 귀속은 별도 출처 대조 후 적용한다.

이전 확대 비교 보고서·세부 해안 진단 JSON·도엽 검토 기록은 현행 자료에서 삭제했다. 이는 해당 변화가 실제로 없었다는 판단이 아니며, 이전 Git 이력은 남는다.
