# 1922 소련·러시아 공화국 중앙아시아 승인 경계 반영

> 보고서 ID: `GEO-USSR-CA-20261026` · 상태: `validated-cartographic-selection` · 지도 반영: `staged-for-publication`
> 기준 자료: `68380579a7c7a1bd8ec97683b7517502c1389c3c`

## 범위
소련 및 러시아 SFSR의 기존 `1922-12-30-reviewed-v2` 형상만 수정한다. 기존 유효기간 1922-12-30~1925-05-12와 국가 존속기간은 변경하지 않는다. 히바·아트렉·사라흐스 3구간은 승인된 선을 최신 외곽의 정확한 원좌표 구간과 교체했다. 부하라 동쪽 파미르 연결은 별도 검토 대기이며 이 초안에는 반영하지 않았다.

아랄해·카스피해·하천 물 자산, 주변 국가, 유럽·드네스트르 수정, 나머지 해안·도서와 다른 시기 형상은 보존한다. 아트렉의 기존 물가 3점/1.653 km 접속은 기존 물가 좌표 재사용이며 물 폴리곤의 수정이나 역사 측량 인증을 뜻하지 않는다.

## 검사와 한계
대상 2개 국가의 source/runtime 4형상에서 정확한 원호 좌표 일치와 부분 교체를 확인했다. 역교체 시 원형상이 완전히 복원되며 이외 정점 순서·구멍·도서는 동일하다. 선택 버전의 형상과 후속 승인 메타데이터를 제외한 국가 존속기간·다른 기간은 동일하다. runtime의 새 content-addressed geometry ref를 역치환하면 나머지 객체가 동일하다.

세 구간의 국소 add/remove가 source/runtime 및 부모·러시아 공화국에서 같고 결과 형상은 유효하다. 전 세계 재계산·다른 국가 데이터 검사는 수행하지 않았다. 물 자산을 변경하지 않았으며 기존 prepared mesh를 새 형상의 해시로 위장하지 않았다. 기존 `prepared-polygon-mesh.js`의 geometry digest 미일치 시 정상 지연 생성 경로를 사용한다.

이는 사용자가 수용한 거시적 역사 지도용 표시선 반영이다. 발행 연도를 관측연도로 확정하지 않으며, 자료 간 측지·일반화 차이와 표시 접합 한계는 [PROVENANCE.md](PROVENANCE.md)를 따른다. 독립 역사 측량 정확도 검증을 완료했다고 주장하지 않는다.

## 저장 상태
히바·아트렉·사라흐스 3구간만 별도 승인 범위로 게시한다. 부하라는 지도 지역 정합 재검토 및 추가 접속 승인 전 보류한다. 데이터 커밋과 app main 통합·공개 반영 상태는 후속 publication-result.json에 구분 기록한다. 이 문서만으로 웹 반영 완료를 뜻하지 않는다.
