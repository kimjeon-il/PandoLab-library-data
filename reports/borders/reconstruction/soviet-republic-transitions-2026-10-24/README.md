## 범위

사용자가 승인한 15개 전환일을 `transitions.json`에 보관한다. 공화국 마지막 날은 전환일 전날, 독립국/현대 국호 단계의 첫날은 전환일이다. 러시아의 1991-12-25는 독립선언일이 아닌 러시아연방 국호 단계다. 기존 객체 ID와 좌표를 유지하며 소련 부모 존속기간은 변경하지 않는다. 이전 1922년 소련·카스피해 적용은 재실행하지 않는다.

`datePrecision`/`geometryDatePrecision`, 편집 화면의 별도 정밀도, 기기 현재 월에 따른 숨은 선택 분기를 제거한다. 연·월·일은 날짜 문자열과 존속기간/형상 기간으로 판단한다. 다른 현존 객체의 실제 기간 조사는 후속 작업이다. 그 객체의 미입력 날짜는 null로 남으며, 기존 기간 의미상 열린 구간이다. 전체 과거 세계지도의 역사적 정확성이 확보되었다는 뜻은 아니다.

## 근거와 기존 좌표 재사용

전환 기준·일차 출처·원문 접근과 검색 대조의 차이는 `transitions.json`에 기록한다. 원문 접근이 막힌 출처를 직접 읽었다고 주장하지 않는다. 별표 4개 기준은 사용자 재확인을 받았다.

- 러시아: 기존 러시아 SFSR 말기 좌표를 1991-12-25–2014-03-17에 재사용한다. 2014-03-18부터 기존 크림 표시 관례의 현대 좌표를 연결한다. 국제법적 주권 판단이 아니다.
- 카자흐스탄: 기존 말기 좌표를 1991-12-16–1995-09-24에 재사용하고 1995-09-25 바이코누르 임대 발효일부터 기존 KAZ/KAB 표시 분할을 연결한다. 임대는 주권 이전이 아니다. 현대 임대 외곽의 당시 세부 선형은 근사다.
- 리투아니아: 기존 1991년 근사 좌표를 전환 참고 연도 1990–1990-03-10에 재사용한다. 1990년을 형상 발생일이나 SSR 전체 시대 복원으로 해석하지 않는다.
- 다른 독립국의 기존 거시 외곽을 승인 전환일부터 재사용하되 역사적 세부 측량과 해안선의 독립 검증으로 표현하지 않는다.
- 아제르바이잔 독립 이후에도 이미 채택된 나고르노카라바흐 표시 우선순위를 이어받는다. 새 경계 좌표는 만들지 않는다.
