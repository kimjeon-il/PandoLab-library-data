# 중국 접경 실제 국가 데이터 반영 — 2026-10-29

## 반영
- `state:soviet-union`, `state:soviet-union-russian-sfsr`의 기존 검토본 유효기간 **1922-12-30~1925-05-12**에 승인된 서부–투바–몽골–만주 외곽을 반영했다.
- `state:MNG`의 같은 기간 북쪽 공유 경계에 **몽골 B 교환 전 경계**와 M01 연결선을 함께 반영했다. 이전·이후 몽골 형상은 원형을 유지한다.
- 이 기간은 기존 소련 검토본의 적용 범위이며, **1925-05-12를 몽골 영토교환일로 판단한 것이 아니다. 교환일은 미확정(null)**이다.
- 최종 선택선은 60개 역할별 구간, 좌표 항목 4,414개/접점 중복 제외 4,355개다. 기존 59개 접점을 그대로 사용했다.
- 국가 원자료, 생성된 v2 국가 청크/색인, native library 객체, 실제 기본지도 v1 국가/시점 바인딩과 전송 묶음을 함께 갱신했다. 단순 검토본 추가로 작업을 끝내지 않았다.

## 보존
- 기존 소련/러시아 SFSR의 다른 기간, 카스피해·아랄해 및 유럽·캅카스·중앙아시아의 기존 교정은 유지했다.
- 기존 컴파일 형상에 승인된 원자료 차분만 적용했다. 몽골에서는 옛 소련 원자료에 의해 잘려 있던 북쪽 부분 중 새 몽골 원자료 소유 범위만 복구해 공백을 없앴다. 전 세계/전체 역사 자료를 다시 생성하지 않았다.
- 현재 중국 객체는 중화인민공화국(1949년 이후)이므로 1922년을 위해 그 존속기간·현대 형상을 변경하거나 새 중화민국 객체를 임의로 만들지 않았다. 아프가니스탄에 새 중첩은 발생하지 않았으므로 별도 형상 변경을 하지 않았다.
- 물·해안 자료, 준비된 폴리곤 메시 캐시, main 및 배포는 변경하지 않았다. 새 형상의 준비 메시가 없는 경우 기존 런타임의 캐시 미스 생성 경로를 사용한다.

## 역사적 한계
M01은 해당 약 305km에 구체적 변경을 특정하는 기록을 찾지 못한 뒤 사용자가 선택한 현대 공유선 재사용이다. 변화가 없었다는 증명은 아니다. 투바·와한은 선택된 실용적 근사이며, 파미르 등의 혼합 연도/명목 좌표와 표시용 접합 가정은 그대로 남는다. 동부 도서 3개 쟁점의 1922년 실효지배는 확정되지 않았다. 이 반영은 승인된 거시적 표시 모델의 채택이지 법정·측량 경계의 인증이 아니다.

## 검증과 CI
- 원자료의 전체/개별 형상 유효성, 공유 경계와 접점, 대상 기간 밖 원형 보존을 검사했다.
- 실제 컴파일 결과의 시점별 형상, 소련–몽골 무중첩 및 공유 경계 연속성, 바인딩/해시/전송 청크를 별도로 검사했다. 상세 결과는 동봉 검증 기록을 따른다.
- 변경한 staged writer의 회귀 테스트와 기존 Caspian 차분 테스트만 실행했다. 전체 테스트를 실행했다는 뜻이 아니다.
- 앱의 이 작업 커밋은 `[skip ci]`로 자동 CI를 실행하지 않는다. 이유는 기존 P2가 이 범위를 넘는 미기록 자료 9개 계열을 자동 재생성하여 이전 compiled-only 교정을 덮어쓸 위험이 있기 때문이다. CI 코드를 바꾸거나 가짜 생성 증명을 넣지 않았다. P1/P2/P3 통과로 보고하지 않는다.
- main 병합은 사용자 담당이다. work/gis 저장·푸시는 배포가 아니다.

## 재현 자료
`selected-route.geojson`은 승인된 버전 2 좌표·출처·기존 불확실성 기록이다. 그 안의 과거 미적용 표시는 입력 당시 상태다. 현재 적용 상태는 이 문서 및 국가 원자료의 `chinaFrontierAdjustment`를 따른다. `recipe.json`은 적용 객체·기간·앵커·원자료 해시를 기록한다. 원자료와 실제 컴파일 결과의 검증은 별개다.
