# 1922 소련·러시아 SFSR 부하라 승인 후속 경계

기준 데이터: `fa27d79b5d9ef0f2449da5e118a835c1c585c6e3`. 승인된 288점과 기존 파미르 강 경계 20.343 km를 재사용해 해당 외곽만 연결했다. 1922-12-30~1925-05-12 기간 및 국가 존속기간은 그대로다. 기존 3구간·유럽·드네스트르 수정, 아랄해·카스피해와 하천 물 자산은 변경하지 않는다.

역사적 영토 교환을 확인한 수정이 아니라 사용자가 수용한 지도 표시선 교정이다. 원도 오류 원인을 단정하지 않는다. 근거는 PAMIR-TREATY-CHECK.md, 정확한 국소 선택은 arc-patch-spec.json 및 selected-arc.geojson에 있다. 새 지역 정합 진단선은 적용하지 않았다.

대상 source/runtime 네 형상은 각각 기존 접점에서 국소 교체했다. 역교체로 모든 기존 좌표·순서와 다른 객체 필드가 복원된다. source/runtime 국소 면적의 약1e-16제곱도 차이는 부동소수 교점 잔여이며 bit-identical Boolean 결과라고 주장하지 않는다. prepared mesh 해시 위장 없이 새 geometry ref의 정상 캐시 미스를 사용한다.

게시 상태는 별도 publication-result.json에 기록한다. 이 보고서만으로 공개 웹 반영을 뜻하지 않는다.
